# Как открыть терминал и вставить команду установки

Установка cheburnet — это **несколько команд**, которые нужно вставить в терминал компьютера
(того, что в одной сети с роутером). Терминал — это программа, которая уже есть в вашей
системе, ставить ничего не надо. Ниже — где её открыть и что делать, по шагам.

> Не хотите терминал вообще? Если на роутере есть веб-панель LuCI — есть
> [способ через браузер](install-no-ssh.md).

---

## Windows

1. Нажмите правой кнопкой мыши по кнопке **«Пуск»** (значок Windows в углу).
2. Выберите **«Терминал»** (в старых версиях — **«Windows PowerShell»**).
   <!-- скриншот: контекстное меню Пуск с пунктом Терминал -->
3. Откроется тёмное окно. Кликните в него, вставьте команду (**правая кнопка мыши** вставляет
   скопированное) и нажмите **Enter**.
   <!-- скриншот: окно PowerShell с вставленной командой -->

Команды для вставки — в разделе [«Шаг 3 — установщик по SSH»](../README.md#шаг-3--установщик-по-ssh).

---

## macOS

1. Нажмите **⌘ (Cmd) + Пробел** — откроется поиск Spotlight.
2. Введите `Terminal` и нажмите **Enter**.
   <!-- скриншот: Spotlight с запросом Terminal -->
3. В открывшемся окне вставьте команду (**⌘ + V**) и нажмите **Enter**.

Команды для вставки — в разделе [«Шаг 3 — установщик по SSH»](../README.md#шаг-3--установщик-по-ssh).

---

## Linux

Нажмите **Ctrl + Alt + T** (в большинстве систем открывает терминал), либо найдите
«Терминал» в меню приложений. Вставьте команду (**Ctrl + Shift + V**) и нажмите **Enter**.

---

## Что происходит после Enter

1. **Первая команда** (`ssh-keygen -R 192.168.1.1; ssh root@192.168.1.1`) подключает компьютер
   к роутеру. Часть `ssh-keygen -R` заранее стирает старый ключ роутера, если компьютер уже
   подключался к устройству на этом IP раньше (например, к этому же роутеру до сброса к
   заводским) — без неё SSH мог бы принять смену ключа за атаку и отказаться подключаться.
   - Спросит про «подлинность хоста» (`Are you sure you want to continue connecting?`) —
     введите `yes` и Enter. Это нормально при первом подключении.
   - Спросит пароль (`root@192.168.1.1's password:`). На свежем OpenWrt он **пустой** —
     просто нажмите **Enter**. Пароль при вводе не отображается — это нормально.
   - Приглашение сменится на `root@OpenWrt:~#` — вы «внутри» роутера.
2. **Вторая и третья команды** (`wget …` и `sh /tmp/cheburnet.sh`) скачивают и запускают
   установщик. Пойдёт установка (1–3 минуты, видно строки прогресса).
3. В конце появится ссылка вида `http://192.168.1.1/cheburnet/?token=…` — **скопируйте её и
   откройте в браузере**. Дальше — мастер настройки. Копирование **из** терминала отличается
   от привычного:
   - **Windows:** выделите ссылку мышью и нажмите **правую кнопку мыши** (или Enter) —
     выделенное попадёт в буфер обмена. **Ctrl+C не нажимайте**: в терминале это
     «прервать программу», а не «копировать».
   - **macOS:** выделите ссылку мышью и нажмите **⌘+C**.
   - **Linux:** выделите ссылку мышью и нажмите **Ctrl+Shift+C**.

## Если что-то пошло не так

- **`Connection timed out` / `Connection refused`** — компьютер не в той же сети, что роутер,
  или адрес роутера не `192.168.1.1`. Проверьте, что подключены к роутеру по кабелю или его
  Wi-Fi. Настоящий адрес роутера — на наклейке снизу корпуса или в свойствах сети компьютера
  (поле «шлюз»/«gateway»); подставьте его в команды вместо `192.168.1.1`.
- **`Permission denied`** — пароль не подошёл. На свежем роутере он пустой (просто Enter);
  если роутер уже настраивали — введите заданный пароль.
- **`REMOTE HOST IDENTIFICATION HAS CHANGED`** — команда из шага 1 уже должна была это
  предотвратить; появляется, если вы вводили `ssh` без `ssh-keygen -R` перед ним (например,
  набрали команду вручную). Выполните `ssh-keygen -R 192.168.1.1` на компьютере и повторите
  подключение.
- **`wget` ругается или скачался пустой файл** — `raw.githubusercontent.com` иногда отдаёт
  пустой ответ. Просто повторите команду `wget` ещё раз. Не помогает совсем — в вашей сети
  сервер с установщиком недоступен, см. [install-blocked.md](install-blocked.md).
- Ничего не помогает — напишите в Telegram, ссылка в [README](../README.md#нужна-помощь).

## Одной командой — для нестабильной сети и автоматизации

Вариант для тех, кому неудобно заходить на роутер вручную: одна команда с компьютера, которая
подключается по SSH, качает установщик с **пятью попытками** и запускает его. Полезна, когда
`raw.githubusercontent.com` в вашей сети часто отдаёт пустой ответ.

**Linux / macOS:**
```bash
ssh-keygen -R 192.168.1.1 2>/dev/null; ssh -o StrictHostKeyChecking=accept-new -o ConnectTimeout=10 root@192.168.1.1 'for i in 1 2 3 4 5; do wget -T 15 -qO /tmp/cheburnet-setup.sh https://raw.githubusercontent.com/andreiyurik/cheburnet-router/master/bootstrap/bootstrap.sh && break; rm -f /tmp/cheburnet-setup.sh; echo попытка $i из 5 не удалась, повтор через 3 секунды; sleep 3; done; if [ -s /tmp/cheburnet-setup.sh ]; then sh /tmp/cheburnet-setup.sh; else echo ОШИБКА: установщик не скачался. Проверьте, что на роутере есть интернет, и запустите команду снова.; fi'
```

**Windows (PowerShell / Терминал):**
```powershell
ssh-keygen -R 192.168.1.1 2>$null; ssh -o StrictHostKeyChecking=accept-new -o ConnectTimeout=10 root@192.168.1.1 'for i in 1 2 3 4 5; do wget -T 15 -qO /tmp/cheburnet-setup.sh https://raw.githubusercontent.com/andreiyurik/cheburnet-router/master/bootstrap/bootstrap.sh && break; rm -f /tmp/cheburnet-setup.sh; echo попытка $i из 5 не удалась, повтор через 3 секунды; sleep 3; done; if [ -s /tmp/cheburnet-setup.sh ]; then sh /tmp/cheburnet-setup.sh; else echo ОШИБКА: установщик не скачался. Проверьте, что на роутере есть интернет, и запустите команду снова.; fi'
```
