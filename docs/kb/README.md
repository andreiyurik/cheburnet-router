# База знаний cheburnet-router

Это **Obsidian-vault** — документация проекта, устроенная так, чтобы быть одинаково
удобной **человеку** (граф взаимосвязанных заметок) и **ИИ** (чистый markdown как контекст).

## С чего начать

- **[[Home]]** — карта всего vault'а (Map of Content) с учебной траекторией и полным списком
  решений. Главная точка навигации.
- **[[conventions]]** — как устроен этот vault и как кормить его ИИ.

## Как открыть

1. **Obsidian:** открой папку `docs/kb/` как vault (Open folder as vault). Заработают граф,
   backlinks, `[[wikilinks]]`.
2. **Просто GitHub/редактор:** это обычный markdown — читается и без Obsidian, ссылки кликабельны.
3. **Скормить ИИ:** см. [[conventions#Для ИИ]] — как собрать контекст одним куском.

## Структура

| Папка | Что внутри |
|---|---|
| `concepts/` | атомарные «как это работает» — сетевые примитивы |
| `architecture/` | как примитивы собраны в систему |
| `decisions/` | ADR — журнал архитектурных решений (и почему) |
| `reference/` | глоссарий, требования, справка |
| `meta/` | конвенции vault'а + процессные документы мейнтейнера (релизы, рефакторинг) |
