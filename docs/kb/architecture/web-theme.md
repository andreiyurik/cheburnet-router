# Тема веб-мастера «плёнка-1969»

> [!tip] TL;DR
> Все цветовые токены [[web-wizard|веб-мастера]] выведены из **реальных кадров кукольного
> мультфильма 1969 года** (не «по памяти»), контраст каждой рабочей пары проверен по WCAG
> скриптом. Две зеркальные тёплые темы: «бумага» (светлая) и «вечерний войлок» (тёмная).

## Зачем своя тема

Дефолтные токены shadcn (zinc + синий) выглядят как любая админка. У проекта есть уникальный
визуальный первоисточник — палитра мультфильма, из которого вырос маскот. Тёплая «книжная»
гамма ещё и совпадает с целевой аудиторией (не-разработчики): дружелюбно, не «хакерская консоль».

## Метод: цвета сняты с плёнки

1. Кадры фильма — миниатюры `hq1/hq2/hq3.jpg` официальных YouTube-загрузок (реальные кадры
   на 25/50/75 % хронометража), 12 кадров из трёх копий.
2. Чёрные поля отрезаны, каждый кадр квантован ImageMagick в 6 доминирующих цветов
   (`convert -crop … -colors 6 -unique-colors`).
3. Полученные кластеры → роли темы. Ключевые первоисточники:
   - **крем/охра** фонов и декораций: `#D5C6A1…#EDF0E3` → `--bg/--card`;
   - **войлок** Чебурашки и тени: `#201A11…#4C2B1E` → `--fg` (светлая) / `--bg` (тёмная);
   - **кирпичный** сюртук Гены: `#A91A19…#BF401B` → `--bad`;
   - **оливковый** кожи Гены: `#505133…#97A76C` → `--ok`;
   - **пыльная бирюза** фонов: `#4C7B8C…#5A958E` → `--accent` (светлая);
   - **горчичный**: `#DBBB44` → `--accent` (тёмная).

Инженерные референсы, по которым выверена структура (не копированы, а сверены):
[Flexoki](https://stephango.com/flexoki) — «чернила на бумаге», калиброванные light/dark-пары;
Gruvbox — многолетне проверенная ретро-гамма с теми же опорными оттенками.

## Два неочевидных решения

- **Акцент меняется между темами.** Горчичный на креме даёт контраст ~1.8:1 — акцентом светлой
  темы быть не может (только декор). На тёмном войлоке он же даёт ~8:1. Поэтому светлая тема
  ведёт бирюзой, тёмная — горчичным: темы зеркальны по характеру, но обе доступны.
- **Токены `--accent-fg` / `--bad-fg`.** Текст на залитых кнопках не хардкодится белым: на
  бирюзе (светлая) он белый, на горчичном (тёмная) — тёмно-войлочный. Заодно ушёл старый баг:
  белый на красном `#f85149` тёмной темы давал 2.9:1.

## Контраст: проверено, не «на глаз»

Юнит-тест `web/src/theme.test.js` парсит токены обеих тем прямо из `app.css` и проверяет все
рабочие пары роль×фон (текст ≥ 4.5:1, основной текст ≥ 7:1, UI-элементы ≥ 3:1) — 22 пары, все
проходят, худшая 5.2:1. Правка токена, роняющая доступность, завалит `npm test`.

## Шрифт

Заголовки — **Nunito 800** (округлый, «книжный», кириллица), вшит в бандл двумя woff2-сабсетами
(latin + cyrillic, **25 КБ суммарно**, лицензия OFL — `web/src/assets/fonts/OFL.txt`). Внешних
запросов нет — UI работает в LAN без интернета. Тело текста — system-ui: техническому контенту
нужна читаемость, характер несут заголовки и цвет.

## Ограничения

- `color-mix()` в тонировках (`.note`, `.banner`, выбранное радио) — baseline 2023; на браузерах
  старее тонировка выпадет в прозрачную (текст и рамки остаются читаемыми).
- Дефолт темы — системная настройка (`prefers-color-scheme`); кнопка в шапке (`ThemeToggle`)
  задаёт явный выбор поверх неё: `data-theme` на `<html>` + `localStorage`, применяется
  инлайн-скриптом в `index.html` до первой отрисовки (иначе мигает системная). Из-за этого
  тёмные токены объявлены в CSS дважды (media-блок и `[data-theme="dark"]`) — их синхронность
  сторожит `theme.test.js`.
