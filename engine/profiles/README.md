# engine/profiles — сохранённые AWG-серверы («страны»)

Несколько конфигов AmneziaWG на одном роутере: ручной выбор из панели и автосмена сторожем.
Почему так устроено и от чего отказались — [ADR 0008](../../docs/kb/decisions/0008-awg-profiles.md).

## Раскладка

- **`profiles.uc`** — ЧИСТО: нормализация списка, добавление/переименование/удаление/порядок,
  `mark_active`, `failover_order`, `decide_failover` (решение автосмены), `public_view` (то, что
  видит панель — без секретов). Юниты — [tests/](tests/).
- **`store.uc`** — I/O: `/etc/cheburnet/profiles.json` (запись через tmp + rename) и
  `/etc/cheburnet/profiles/pN.conf` (права 600 ставятся ДО записи ключа). `commit_conf` зовут
  `install/replace_vpn.uc` и `install/run.uc` после подтверждённого рукопожатия.

## Инварианты

- Профиль — это файл, а не туннель: интерфейс один (`awg0`), применяет его `replace_vpn.uc` с автооткатом.
- Активным профиль становится только после свежего рукопожатия; откатившийся сервер активным не числится.
- Активный профиль удалить нельзя — на нём держится дом.
- Имя файла — из счётчика (`p1`, `p2`, …), никогда из ввода пользователя; id из RPC сверяется со списком.
- Порядок списка = приоритет автосмены.

## Использование на роутере

```sh
cat /etc/cheburnet/profiles.json                        # список, активный, автосмена
logread -e cheburnet-watchdog                            # что делала автосмена
```
